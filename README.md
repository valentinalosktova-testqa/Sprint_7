# Проект Sprint_7. Тестирование API Яндекс.Самокат

## Описание
Проект содержит автотесты для API учебного сервиса Яндекс.Самокат.

## Стек
- Python 3.14
- Pytest
- Requests
- Allure

## Установка и запуск
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить тесты: `pytest`
4. Сгенерировать Allure-отчёт: `allure generate allure_results -o allure-report --clean`

## Структура проекта
- `tests/` — тесты для API
- `helpers/` — вспомогательные функции
- `data/` — URL-адреса
- `allure_results/` — результаты тестов
- `allure-report/` — Allure-отчёт
